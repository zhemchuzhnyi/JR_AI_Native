# team-kit

Плагин Claude Code с навыками для безопасной работы с Git-коммитами и улучшения промптов для разработки на JavaScript и TypeScript.

## Навыки

- **git-commit** — анализирует изменения и создаёт один логически связанный коммит в формате Conventional Commits.
- **prompt-improve** — уточняет цель, требования и ограничения задачи, затем возвращает готовый промпт с критериями готовности. Не выполняет описанную в промпте задачу.

## Локальный запуск

Из корня репозитория запусти Claude Code с плагином:

```bash
claude --plugin-dir ./team-kit
```

## Вызов навыков

В Claude Code используй команды:

```text
/team-kit:git-commit
/team-kit:prompt-improve
```

## Ограничения `git-commit`

- Создаёт не более одного коммита за запуск и не выполняет `git push`.
- Выбирает только один логически связанный набор файлов; не включает не изученные или несвязанные изменения.
- Добавляет в индекс файлы по явным путям; не использует `git add .` или `git add -A`.
- Не использует `--amend` и `--no-verify`, не изменяет остальные изменения пользователя.
- Если выбор файлов неясен — сначала спрашивает пользователя; если коммит не удался, сообщает об ошибке и останавливается.
