

# CLAWD Wisdom

Одностраничный сайт с пиксельным маскотом Claude Code. Маскот следует за курсором мыши; когда мышь не двигают — свободно плавает по экрану. Клик в любом месте показывает одну короткую подсказку о работе с Claude Code; на странице виден счётчик открытых подсказок.

## Правила проекта

- **Только эти файлы**: `index.html`, `styles.css`, JavaScript в `js/script.js` и спрайт `assets/clawd.svg`. Никаких других файлов без явного запроса.
- **Без npm, сборки, фреймворков и бэкенда.** Чистые HTML/CSS/JS, страница открывается через `file://` или любой статический сервер.
- **Без внешних шрифтов и сетевых запросов.** Никаких CDN, Google Fonts, `fetch` и т.п.
- **Вся анимация — через `transform` внутри одного animation loop** (один `requestAnimationFrame`-цикл). Никакой анимации через margin/top/left, никаких множественных rAF-циклов.
- **Классические скрипты с `defer`; одно глобальное namespace на всё приложение** (например, `window.CLAWD`). Никаких inline-стилей и inline-скриптов: все стили в `styles.css`, весь JS в `js/script.js`.
- **Строки интерфейса — на английском** (заголовки, счётчик, подписи). **Текст подсказок — на русском.**

## Структура

```
index.html       — каркас страницы: заголовок, подпись, счётчик, маскот
styles.css       — все стили (светлая тема, терракотовый акцент, позиционирование)
js/script.js     — весь JS: namespace CLAWD, движение маскота, счётчик
assets/clawd.svg — спрайт маскота (SVG)
```

## Рабочие термины

- **маскот** — спрайт CLAWD (`assets/clawd.svg`), движущийся по странице;
- **подсказка** — короткий русский текст о работе с Claude Code, показывается по клику;
- **animation loop** — единый цикл `requestAnimationFrame`, в котором живёт всё движение маскота;
- **namespace** — единственный глобальный объект (напр. `window.CLAWD`), через который работает всё приложение.
