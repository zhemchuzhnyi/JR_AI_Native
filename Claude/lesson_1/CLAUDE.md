# CLAWD Wisdom — правила проекта

## Назначение

Одностраничный статический сайт с пиксельным маскотом Claude Code. Маскот следует за курсором, а при отсутствии движения плавно перемещается по экрану. Клик по странице показывает одну короткую подсказку о работе с Claude Code; интерфейс отображает количество открытых подсказок.

## Обязательные ограничения

- Рабочие файлы проекта: `index.html`, `styles.css`, `js/script.js` и `assets/clawd.svg`. Новые файлы создаются только по прямому запросу.
- Используются только чистые HTML, CSS и JavaScript. Не добавлять npm, сборку, фреймворки, библиотеки или бэкенд.
- Страница должна работать через `file://` и через любой простой статический сервер.
- Не использовать внешние шрифты, CDN, сетевые запросы, `fetch` и другие внешние зависимости.
- Вся анимация выполняется через `transform` внутри одного общего цикла `requestAnimationFrame`. Не анимировать положение через `top`, `left`, `margin` и не создавать дополнительные циклы анимации.
- Подключать классические скрипты с `defer`. Inline-скрипты и inline-стили запрещены.
- Всё состояние и публичные функции JavaScript должны находиться в одном namespace приложения, например `window.CLAWD`.
- Строки интерфейса (заголовки, подписи, счётчики и кнопки) должны быть на английском языке. Тексты подсказок должны быть на русском языке.

## Ответственность файлов

```text
index.html       — структура страницы и подключение ресурсов
styles.css       — все стили, темы, layout и визуальные состояния
js/script.js     — namespace CLAWD, интерактивность, движение и счётчик
assets/clawd.svg — SVG-спрайт маскота
```

## Правила внесения изменений

1. Перед изменением прочитать относящиеся к задаче файлы и понять существующую структуру.
2. Вносить минимальное изменение, необходимое для запроса; не выполнять несвязанный рефакторинг.
3. Сохранять текущую архитектуру, имена и стиль кода, если задача не требует их изменения.
4. Не добавлять зависимости, файлы, сетевые вызовы или настройки, не предусмотренные проектом.
5. Не размещать секреты, токены, ключи, персональные данные и локальные машинные пути в коде, документации или истории изменений.
6. Не передавать конфиденциальные данные в подсказки, логи, URL или сообщения об ошибках.
7. Считать пользовательский ввод и внешние данные недоверенными: экранировать текст при вставке в HTML и не выполнять полученное содержимое как код.
8. Не менять поведение за пределами согласованного объёма. Если требования противоречат друг другу, остановиться и обозначить конфликт.

## Проверка результата

После изменения:

- проверить diff и убедиться, что изменены только ожидаемые файлы;
- проверить корректность относительных путей к CSS, JavaScript и SVG;
- убедиться, что JavaScript подключён с `defer`, а inline-кода нет;
- открыть страницу через `file://` или статический сервер, если изменение затрагивает поведение или отображение;
- проверить отсутствие ошибок в консоли браузера;
- проверить движение маскота, реакцию на курсор, плавное плавание без движения мыши, показ подсказки по клику и обновление счётчика;
- явно сообщить о пропущенных проверках и о любых неустранённых ошибках.

## Термины

- **Маскот** — спрайт `assets/clawd.svg`, который движется по странице.
- **Подсказка** — короткий русский текст о работе с Claude Code, показываемый по клику.
- **Animation loop** — единый цикл `requestAnimationFrame`, в котором обновляется движение маскота.
- **Namespace** — единственный глобальный объект приложения, например `window.CLAWD`.
