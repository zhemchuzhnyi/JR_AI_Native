## Краткий конспект

Лекция знакомит с Claude Code как агентом для разработки: чем он отличается от чата, как устроен цикл его работы и почему разработчик отвечает за проверку результата и diff. Разбираются установка и первый запуск на macOS, Linux и Windows, базовые команды и работа из IDE.

Отдельные темы — безопасное начало работы с Git, приоритеты настроек, структура `.claude/`, назначение `CLAUDE.md`, локальных правил и auto memory, а также режимы разрешений и автономности. В завершение показываются создание и доработка CLAWD Wisdom, практики CLAWD YOLO и CLAWD Runner и публикация проекта в сети.
